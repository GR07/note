# 循环神经网络 - RNN

在前馈神经网络的基础上，增加了一份可以不断向后传递的信息


# 核心思想

初始有一个隐藏状态，每读到新的内容，就全量压缩覆盖（内容转化词向量再压缩），理论上解决了，对输入的内容，记忆长度有限的问题。

隐藏状态 = 模型的记忆 = 所有文字信息 = 一组高维向量


# 流程

1. 设置初始隐藏状态

2. 输入后，把输入转成词向量

3. RNN 把输入的词向量和隐藏状态放在一起，进行加权求和及非线性变换（可以理解为压缩），得到一份新的隐藏状态（所有信息的摘要）。

   注意：上一步的颗粒度是单个 Token 词元，也就是一句话可能会被处理成百上千次。
   

5. 随着输入内容，不断的刷新迭代隐藏状态

6. 最后，传给下一个位置，传给输出层（计算概率）完成下一次词的预测


# 问题

因为隐藏状态的维度是固定的，随着每次新的压缩覆盖，导致越前面的信息越模糊（梯度消失）
