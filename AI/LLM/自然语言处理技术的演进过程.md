


# N-gram 

统计词语组合预测下一个词

问题：依赖已统计的组合，未出现的词永远不会被用到，不能理解语义关系，不能泛化


# 词嵌入向量 - Embedding

通过大量训练，把词元变成具有高维度空间的坐标（一组数字），所以可以通过数字接近，来判断语义关系。


# 前馈神经网络

把词向量输入神经网络，通过加权求和/非线性变换，获得泛化能力

问题：对输入内容记忆长度有限



# 循环神经网络 - RNN

前馈神经网络的基础上增加了隐藏状态，会把信息压缩覆盖后一直往后传递。

问题：不能稳定长期保存信息，因为不断的压缩后，内容会越来越模糊，被稀释。



# 长短期记忆网络 - LSTM

循环神经网络的基础上增加细胞状态和门控机制（自我删除/选择性存入/选择性读取）

问题：因为是按照词元顺序压缩传递计算，所以很难大规模并行计算，效率低下。



# Transformer

解决 LSTM 的问题

可以做到每个 Token 直接寻找和自身相关的信息
