# 神经元

灵感来自于人大脑的生物神经元

从上游接收一堆信号，加权求和，传给激活函数，最后输出


# 核心处理流程

输入几个物体的指标，对每个指标打分，每个指标各乘一个权重，再把得分相加，减去一个门槛（前面过程叫softmax），再通过一道激活函数（非线性函数），得出结果 1（是） 或 0（不是）


# softmax（归一化指数函数）

比如一组指标，猜四种水果，把每种水果减去门槛的最终得分，通过指数函数转成概率，概率最高的就是当前水果。

问题：当某个指标的分数越高且权重过大时，概率会不准确，所以最后需要传给激活函数（非线性函数）去界定中间区间。



# 神经网络训练

指标打分、权重、偏移，门槛分数线、等确定性的指标，都是通过大量阅读训练调整得到的（神经网络训练）。



# 激活函数

一次函数 y = x
二次函数 y = x²
正弦函数 y = sin(x)
反比例函数 y = 1/x
指数函数 y = 2x
对数函数 y = log2(x)



# 神经网络

神经元得出的结果再传给下一层神经元，这就是神经网络。

最开始的一层叫输入层，中间的所有层叫隐藏层，最后一层叫输出层。

也就是说，神经网络的过程，就是把指标 softmax（归一化）后，通过无数个线性和非线性函数计算出来的结果。
