# N-gram

N-gram 是早期语言模型的基本思路

完形填空，根据前面的词，预测下一个词。


# 核心思想

根据前面的词，对过去出现过的词组合进行统计，出现频率最高的是下一个词。

接收的是文本字符串，基于文本字符串，进行统计预测。


# 几元模型

根据前面 一 个词 - bigram
根据前面 二 个词 - trigram
根据前面 N  个词 - N-gram


# 预测单位

（完整的词语 / 一个字 / 标点符号） = 词元 = Token

常见的词语保留为一个 Token
不常见的的词语，会被拆分，直到一个字是一个 Token



# 问题

基于文本字符串进行统计预测

依赖已统计的组合，未出现的词永远不会被用到，不能理解语义关系，不能泛化
