# 词嵌入向量

通过一组连续数字，描述人类语言的语义。


# 核心思想

通过机器大量学习，用高维度空间的坐标，来表达一个词


# 举例 - 二维空间

先建立一个 x y 坐标轴

假设书包有 2 个属性，颜色、尺寸。

颜色是 x 坐标轴上的一个数值 6
尺寸是 y 坐标轴上的一个数值 2

那么书包的向量就是 6,2


# 举例 - 千维空间

创建一千个坐标轴

这个词可以有 1000 个属性。

这个词转向量就是 6,2,3,5,6,3,7,4,7...


# 文字转化向量 - 目的

可以用数字来表达词了

那么当两个词的空间坐标（数字）越接近，代表着这两个词的语义越相近。

有了语义关系，至此模型开始拥有了泛化能力。
