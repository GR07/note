# 翻译词向量

现实人如何翻译？

先读懂中文，再用笔写成英文


# 两部分 读 / 写

- 编码器：负责读
- 解码器：负责写


# 编码器

前面输入自然语言转成词向量，再加上位置信息，再通过层层自注意力和FNN的过程就是编码器


# 解码器

一个 Token  一个 Token 的去预测生成。

必须只能看到自己和前面的 Token，不允许看到后面的。


## 解码器三步处理流程


- 掩码自注意力

做到只看前面已生成的内容

通过把后面的注意力分数变小，再通过 softmax 计算后，后面的 Token 无限接近 0 相当于被遮蔽，就是掩码自注意力。


- 交叉注意力

解码器可以查询编码器，看看原文

解码器在生成下一个词的时候，可以通过解码器的 Query 去 查编码器的 Key / Value


- 前馈神经网络

思考分析处理

综合处理，得出下一个词（此时依然是向量，还不是一个自然语言词），再把向量打分，通过 softmax 归一化变成概率，概率最高的就是自然语言词，由此循环，直到结束符。
