
#  问题

为了理解更深度的语义，需要抽象的基本单元层数就越多，当产生误差时最后一层需要向第一层反向传播矫正参数。

随着基本单元层数的增加，最后一层和第一层之间的传播信号就变得微弱，因为本质还是 链式传导（梯度消失）。



# 残差连接 - 解决梯度消失


- 推导过程

初始 a

b = b(a) + a

c = c(b) + b

d = d(c) + c

此时要训练 d，就只需要训练减去 c 之后的 d(c) 的结果，而加号后面的就是要传播的信息，做到无损反向传播。


- 公式

y = f(x) + 1

下一个值 = 输出 + 输入

类似于 LSTM，只不过向后传递的信息是原始信息。
