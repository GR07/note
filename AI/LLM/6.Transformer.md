# 注意力机制 ATTENTION


## 核心思想

每个词（token）都和整个上下文做关联，所关联的信息按照权重分配。


## 关联上下文的过程

### 定义 Query 

一个向量，代表用当前词去全文查什么


### 定义 Key 

一个向量，代表每个词可以被匹配到的 Key


### Query 如何匹配 Key

逐个匹配打分，通过 Softmax（归一化）把分数转成权重。

注：匹配的过程得分，还是通过大量的训练


### 定义 Value

匹配到 Key 之后，拿到的 Value 就是真正需要被读取的信息 


### Q / K / V 三件套

从上述过程得出结论，每个词有三个向量构成

- Query
- Key
- Value


### Q / K / V 的来源

单个词向量 -> 按顺序通过三组独立线性变换 依次得出三组数字（Q / K / V）

线性变换 = 训练


### 全新向量

匹配全文后，得出全新的向量。

全新向量 = 当前Token融合上下文的结果 =（每个词的权重 * 每个词的 Value）++
