# 定义

大语言模型本身只是一个用一堆过时数据训练出来的产物，并不会知道实时的数据，

MCP 的出现就是让大模型拥有使用各种外部工具的能力，从而解答实时的问题（天气、指定的股票数据等）。


# Function Calling 

定义标准的 HTTP API 说明书（输入/输出 - JSON 格式）

问题：智能体需要很多的外部工具，那就需要维护很多这种说明书，很麻烦且不安全。


# MCP 诞生

所以为了解决 Function Calling 的麻烦

Anthropic 公司在 2024年11月25号发布的一个协议 - MCP（Model Context Protocol 模型上下文协议）

本质只是对原有的 HTTP API 工具套了一层，就变成了 MCP Server，就可以在模型交互流程里被 MCP HOST（智能体内部） 调用了。

套的这一层做了什么：就是把函数和一段描述函数功能的纯文本绑定在一起，方便大模型理解和调用。（可以看 cline 源码 或抓包看请求体）


# MCP HOST（MCP Client 集成在智能体内部）

支持 MCP 协议的软件（也就是智能体 cloud / cursor 等）

借助它才能调用 MCP Server 



# MCP Server

非传统的服务器（例：访问谷歌网站，即是访问谷歌服务器）

MCP Server 指这个工具的执行是符合 MCP 协议的

MCP Server 都是本地通过 Node 或 Python 启动（联网/不联网）
