# 权限控制体系

划分成了三个不同粒度的层级

1. 全局配置

2. 精细化配置

3. 工具内设置




# 全局配置

5 种全局运行模式（Mode）

举例：整个系统允许调用的最高频次、全局的黑名单 IP、所有 Agent 绝对不能访问的敏感系统路径（如 /etc/shadow）、统一的 API 超时时间等。

1. DEFAULT（默认模式 - 最严格）
行为：最保守的安全策略。除了内置放行一些只读命令（如 ls, cat 查看文件），任何具有修改性质的操作都需要明确的规则允许，或者弹出提示让用户确认（Ask）。

适用：生产环境。绝不希望 AI 乱改代码或系统，宁可繁琐一点也要保证安全。

2. ACCEPT_EDITS（接受编辑 - 信任工作区）
行为：在指定的“工作目录”内放开手脚。如果是新建目录、删除文件（mkdir, rm）等操作，自动放行；执行 Bash 命令时，只要操作路径不超出工作目录，也自动放行。

适用：活跃的开发场景（用户在场）。这对应了前面提到的 Workspace 隔离概念，只要 Agent 在自己的“沙盒”里折腾，就不去打断它。

3. EXPLORE（探索模式 - 只看不动）
行为：纯粹的“只读”模式。只允许运行只读工具和命令，拒绝一切写入或修改的请求。

适用：让 Agent 做代码分析、梳理项目结构、制定计划等不需要动手改文件的场景。

4. BYPASS（绕过模式 - 放飞自我）
行为：跳过所有安全/权限检查。除非有极其强硬的 deny（拒绝）规则，否则随便折腾。

适用：完全可信的沙箱环境。比如在一个用完即毁的 Docker 容器里，或者一次性的 E2B 虚拟机里，让 Agent 尽情发挥（比如做漏洞测试、随意安装环境）。

5. DONT_ASK（禁止询问 - 彻底自闭）
行为：当系统遇到需要用户确认（Ask）的操作时，不弹出提示，直接转为拒绝（Deny）。

适用：无人值守的自动化脚本。比如半夜定时跑的任务，没有真人坐在电脑前点“同意”，所以一律拒绝需要确认的高风险操作，防止程序卡死等待。


# 精细化配置

配置哪些命令可以执行/不可执行或询问

举例：“财务 Agent 只能在财务 workplace 中调用资金 API，客服 Agent 无法越权”。这就是精细化配置，它根据 Agent 的职责或当前所处的“房间”来分配权限。


全局 + 精细化 示例
```python
# ==========================================
# 1. 导入依赖库
# ==========================================
from agentscope.agent import Agent  # 导入智能体类
from agentscope.workspace import (LocalWorkspace,  # 导入本地工作空间类，用于在本地文件系统运行工具
                                  DockerWorkspace,  # 导入 Docker 工作空间类（图中未使用），用于在 Docker 容器隔离环境运行
                                  E2BWorkspace)  # 导入 E2B 工作空间类（图中未使用），用于在云端沙盒环境运行
from agentscope.model import OpenAIChatModel  # 导入模型类
from agentscope.credential import OpenAICredential  # 导入凭证类
# 导入权限上下文和权限模式
from agentscope.permission import PermissionContext, PermissionMode
from agentscope.permission import PermissionRule, PermissionBehavior
from agentscope.tool import Toolkit

# ==========================================
# 2. 精细化权限配置 (Permission Context)
# ==========================================
permission_context = PermissionContext(  # 实例化权限上下文对象
    mode=PermissionMode.ACCEPT_EDITS,  # 设置全局默认模式为“接受编辑”（即自动批准在本地工作目录内的修改）
    
    # --- 白名单规则 (自动允许) ---
    allow_rules={  # 定义自动放行的规则集合
        "Bash": [PermissionRule(  # 针对 Bash 工具（执行终端命令）配置规则
            tool_name="Bash",  # 指定工具名称
            rule_content="npm run:*",  # 匹配规则：允许所有以 "npm run:" 开头的命令 (如 npm run build)
            behavior=PermissionBehavior.ALLOW,  # 行为设定为：允许 (ALLOW)
            source="userSettings"  # 规则来源标记为用户设置
        )]
    },
    
    # --- 黑名单规则 (直接拒绝) ---
    deny_rules={  # 定义直接拒绝的规则集合
        "Bash": [PermissionRule(  # 同样针对 Bash 工具
            tool_name="Bash",  # 指定工具名称
            rule_content="rm:*",  # 匹配规则：拒绝所有以 "rm:" 开头的命令 (如 rm -rf /，防止误删文件)
            behavior=PermissionBehavior.DENY,  # 行为设定为：拒绝 (DENY)
            source="userSettings"  # 规则来源标记为用户设置
        )],
        "AddNumbers": [PermissionRule(  # 针对 AddNumbers 工具
                tool_name="AddNumbers",
                rule_content="",  # 拒绝执行的危险命令
                behavior=PermissionBehavior.DENY,  # 行为：拒绝
                source="userSettings"
            )]
    },
    
    # --- 询问规则 (需用户确认) ---
    ask_rules={  # 定义需要用户手动确认的规则集合
        "Write": [PermissionRule(  # 针对 Write 工具（写文件）配置规则
            tool_name="Write",  # 指定工具名称
            behavior=PermissionBehavior.ASK,  # 行为设定为：询问 (ASK)，执行前需用户批准
            rule_content="",  # 匹配内容为空，表示拦截所有使用 Write 工具的操作
            source="userSettings"  # 规则来源标记为用户设置
        )]
    }
)
# ==========================================
# 3. 初始化工作空间 (Workspace)
# ==========================================
workspace = LocalWorkspace(workdir="./my_agent_workspace")  # 实例化本地工作空间，指定工作目录为当前目录下的 my_agent_workspace 文件夹
await workspace.initialize()  # 异步初始化工作空间（例如：创建目录、检测环境依赖等）

# ==========================================
# 4. 模型配置 (Model)
# ==========================================
model = OpenAIChatModel(  # 实例化大语言模型对象
    credential=OpenAICredential(  # 传入 API 凭证
        api_key="xxx",  
        base_url="xxx",  
    ),
    model="qwen3.6-flash",  
)

# ==========================================
# 5. Agent 实例化
# ==========================================
agent = Agent(  # 实例化智能体
    name="my_assistant",  # 智能体名称
    system_prompt="你是一个有帮助的助手。",  # 系统提示词
    model=model,  # 绑定上面配置的模型
    toolkit=Toolkit(tools=tools),  # 绑定工具集
    offloader=workspace,  # 绑定工作空间执行器
    state=AgentState(permission_context=permission_context),  # ⚠️关键：将上方的精细化权限上下文注入到 Agent 的运行状态中
)
```



# 工具内设置

含义：这是颗粒度最细的权限，直接深入到某个具体的“工具（Tool）”或“函数”内部。

举例：比如给 Agent 配置了一个 execute_sql 工具。全局配置可能允许它用这个工具，精细化配置允许它在“测试库”使用这个工具，但工具内设置规定这个 SQL 工具只能执行 SELECT 查询，不能执行 DROP TABLE 删除表；或者一个文件读取工具，内部设置限制了它只能读取当前工作目录下的文件，防止越权读取宿主机文件。


```python

# ==========================================
# 1. 导入依赖库
# ==========================================
import asyncio  # 导入异步 I/O 库，用于支持异步编程
from agentscope.agent import Agent  # 导入智能体核心类
from agentscope.workspace import (LocalWorkspace,  # 导入本地工作区类
                                  DockerWorkspace,  # 导入 Docker 工作区类
                                  E2BWorkspace)  # 导入 E2B 工作区类 # 导入本地工作区
from agentscope.model import OpenAIChatModel  # 导入大语言模型类
from agentscope.credential import OpenAICredential  # 导入凭证类
from agentscope.message import Msg, TextBlock  # 导入消息类和文本块类
from agentscope.tool import Toolkit, ToolChunk, ToolBase  # 导入工具集类、工具返回块类和工具基类
from agentscope.event import (RequireUserConfirmEvent, ConfirmResult,  # 导入需要用户确认的事件类、确认结果类
                              UserConfirmResultEvent)  # 导入用户确认结果事件类
from agentscope.permission import PermissionContext, PermissionMode  # 导入权限上下文和全局权限模式
from agentscope.state import AgentState  # 导入 Agent 状态类
from agentscope.permission import (PermissionRule, PermissionBehavior,  # 导入权限规则、权限行为(ALLOW/DENY/ASK)
                                   PermissionDecision)  # 导入权限决策类

# ==========================================
# 2. 自定义工具类 (Tool)
# ==========================================
class AddNumbersTool(ToolBase):  # 定义一个继承自 ToolBase 的自定义工具类
    name = "AddNumbers"  # 工具名称
    description = "将两个数字相加并返回结果。"  # 工具描述，大模型会读取此描述来决定是否调用该工具
    input_schema = {  # 定义工具输入参数的 JSON Schema，告诉大模型需要传入什么参数
        "type": "object",  # 参数类型为对象
        "properties": {  # 定义具体的参数属性
            "a": {"type": "number", "description": "第一个数字"},  # 参数 a：数字类型
            "b": {"type": "number", "description": "第二个数字"},  # 参数 b：数字类型
        },
        "required": ["a", "b"],  # 声明 a 和 b 是必传参数
    }
    is_concurrency_safe = True  # 声明该工具是否线程安全（可并发调用）
    is_read_only = False  # 声明该工具是否只读（不改变系统状态）

    async def check_permissions(  # 自定义的权限检查方法（在工具执行前拦截）
        self,
        tool_input: dict,  # 模型打算传入的参数
        context,  # 上下文信息
    ) -> PermissionDecision:  # 返回一个权限决策对象
        a = tool_input.get("a")  # 获取参数 a
        b = tool_input.get("b")  # 获取参数 b
        if isinstance(a, (int, float)) and isinstance(b, (int, float)):  # 检查 a 和 b 是否都是数字
            if a > 10000 and b > 10000:  # 如果两个数字都非常大（比如大于10000）
                return PermissionDecision(  # 返回一个决策：需要询问用户
                    behavior=PermissionBehavior.ASK,  # 行为为 ASK（询问）
                    message=f"两个数 {a} 和 {b} 均大于 10000，请确认是否允许计算加法？",  # 提示用户的信息
                )
            return PermissionDecision(  # 如果数字正常，则返回决策：允许执行
                behavior=PermissionBehavior.ALLOW,  # 行为为 ALLOW（允许）
                message="常规加法操作，已允许。",  # 提示信息
            )

    async def __call__(  # 工具的实际执行入口
        self,
        a: float,  # 接收参数 a
        b: float,  # 接收参数 b
    ):
        result = a + b  # 执行加法计算
        return ToolChunk(  # 将结果包装成 ToolChunk 返回给 Agent
            content=[TextBlock(text=f"计算结果: {a} + {b} = {result}")],  # 提供给大模型看的文本结果
            metadata={  # 额外的元数据信息
                "result": result,  # 具体结果
                "operands": {"a": a, "b": b},  # 操作数
            },
        )

# ==========================================
# 3. 主运行逻辑函数
# ==========================================
async def basic_usage():  # 定义异步主运行函数
    # --- 初始化工作区与工具 ---
    workspace = LocalWorkspace(workdir="./my_agent_workspace")  # 初始化本地工作目录
    await workspace.initialize()  # 异步初始化工作区
    tools = await workspace.list_tools()  # 获取工作区自带的工具列表
    tools.append(AddNumbersTool())  # 将我们自定义的 AddNumbersTool 追加到工具列表中

    # --- 初始化模型 ---
    model = OpenAIChatModel(  # 实例化大模型对象
        credential=OpenAICredential(  # 配置凭证
            api_key="xxx",  
            base_url="xxx",  
        ),
        model="xxx",  # 指定使用的模型
    )

    # --- 配置全局权限规则 ---
    permission_context = PermissionContext(  # 实例化权限上下文
        mode=PermissionMode.ACCEPT_EDITS,  # 全局默认模式：接受修改
        allow_rules={  # 自动放行的白名单规则
            "Bash": [PermissionRule(  # 针对 Bash 工具
                tool_name="Bash",
                rule_content="npm run:*",  # 允许执行 npm run 开头的命令
                behavior=PermissionBehavior.ALLOW,  # 行为：允许
                source="userSettings"
            )]
        },
        deny_rules={  # 自动拒绝的黑名单规则
            "Bash": [PermissionRule(  # 针对 Bash 工具
                tool_name="Bash",
                rule_content="rm:*",  # 拒绝执行 rm 开头的危险命令
                behavior=PermissionBehavior.DENY,  # 行为：拒绝
                source="userSettings"
            )]
        },
    )

    # --- 实例化 Agent ---
    agent = Agent(  # 创建智能体
        name="my_assistant",  # 智能体名称
        system_prompt="你是一个有帮助的助手。",  # 系统提示词
        model=model,  # 绑定模型
        toolkit=Toolkit(tools=tools),  # 绑定包含自定义工具的工具箱
        offloader=workspace,  # 绑定工作区执行器
        state=AgentState(permission_context=permission_context),  # 绑定权限上下文
    )

    # --- 对话循环 ---
    confirm_event = None  # 初始化确认事件为 None
    while True:  # 开启无限对话循环
        if confirm_event is None:  # 如果没有待确认的事件（普通对话）
            user_msg = input("user>>>")  # 获取用户输入
            # 拼接一段上下文提示词，告诉模型当前的工作目录
            user_msg = r"++<<你的工作目录是C:\Users\EDY\agentscope_project\m..." + user_msg
            # 将输入封装为标准的 Msg 对象
            user_msg = Msg(role="user", content=[TextBlock(type="text", text=user_msg)], name="user")
        else:  # 如果有待确认的事件（正在处理权限确认）
            user_msg = confirm_event  # 将确认结果作为新的消息发送给模型
            confirm_event = None  # 清空待确认状态

        print("agent>>>")  # 打印提示符
        # 开始流式获取 Agent 的回复
        async for event in agent.reply_stream(user_msg):
            # 如果遇到需要用户确认的事件（例如触发了自定义工具中的 ASK 权限）
            if isinstance(event, RequireUserConfirmEvent):
                confirm_results = []  # 初始化结果列表
                for tc in event.tool_calls:  # 遍历需要确认的工具调用
                    # 在控制台询问用户是否同意（Y/N）
                    is_confirmed = input(f"\nsystem>>>是否同意调用{tc.name}(Y/N), {tc.input}:") in ["Y", "y"]
                    # 将用户的决定封装成 ConfirmResult
                    confirm_results.append(ConfirmResult(
                        confirmed=is_confirmed,  # True 表示同意，False 表示拒绝
                        tool_call=tc,  # 传入原始的 tool_call
                        rules=tc.suggested_rules,  # 传入建议规则
                    ))
                # 构造用户确认结果事件，准备发送给 Agent
                confirm_event = UserConfirmResultEvent(
                    reply_id=event.reply_id,  # 关联对应的回复 ID
                    confirm_results=confirm_results,  # 传入用户的决定结果
                )
            # 如果事件包含文本增量（正常的流式文本输出）
            elif hasattr(event, "delta"):
                print(event.delta, end="", flush=True)  # 打印文本片段，实现打字机效果
        print("\n")  # 一轮对话结束后换行

# ==========================================
# 4. 程序入口
# ==========================================
if __name__ == "__main__":  # 确保脚本被直接运行时才执行
    asyncio.run(basic_usage())  # 运行异步主函数
```


















# 权限体系总结

纵深防御（Defense in Depth）：
这种结构构成了多层保护网。即使 Agent 绕过了全局限制，或者被分配了错误的精细化角色，工具内部的硬性逻辑还能兜底，防止造成实质性破坏。

最小权限原则（Least Privilege）：
配合第二张代码图中的 permission_context（权限上下文），系统可以精准地给 Agent 下发刚好够用的权限，绝不多给。

灵活性与安全性的平衡：
全局配置定基调，精细化配置定业务边界，工具内设置保底层安全。
