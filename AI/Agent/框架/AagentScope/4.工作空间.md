# Workplace（工作空间）

它在物理（逻辑）层面把不同的 AI Agent 和它们的资源进行了划分和圈定。

为了让多个 AI 代理安全、高效、不混乱地工作，必须给它们分配独立的“工作空间（Workplace）”


# Workplace 的四大核心作用


1. 环境隔离与专注
问题：如果没有 Workplace，所有 Agent（比如客服 Agent 和库存 Agent）混在一个全局空间里，会互相干扰信息，导致环境混乱。

解决：Workplace 就像独立的“房间”（如图中的 C盘、D盘、E盘），把不同任务的 Agent 隔离开，让它们只关注自己相关的信息和资源。


2. 资源与权限管理
问题：不同角色的 Agent 权限不同，不能越权。

解决：Workplace 规定了 Agent “能看见什么”、“能用什么”。比如，财务 Agent 只能在财务的 Workplace 里调用资金 API，客服 Agent 则无法越权访问。这实现了最小权限原则，保障系统安全。


3. 协作的秩序化
问题：多个 Agent 协作时，如果互相直接发消息，容易造成“广播风暴”（信息轰炸）和混乱。

解决：Workplace 充当了一个“公告板”或“黑板”的角色。Agent 在这里有序发布子任务结果，其他 Agent 按需订阅。大家只在公共区域交接工作，避免了无序干扰。


4. 生命周期管理
问题：任务完成后，临时创建的 Agent 如果不清理，会占用系统资源。

解决：Workplace 作为一个“容器”，可以统一启动、暂停、销毁内部的所有 Agent。比如处理完一批订单，一键销毁该订单 Workplace 内的所有临时 Agent，而不影响整个系统。


# 配置代码

```python
# ==========================================
# 1. 导入依赖模块
# ==========================================
from agentscope.agent import Agent  # 导入 Agent 核心类，用于创建智能体
from agentscope.workspace import (LocalWorkspace,  # 导入本地工作空间类，用于在本地文件系统运行工具
                                  DockerWorkspace,  # 导入 Docker 工作空间类（图中未使用），用于在 Docker 容器隔离环境运行
                                  E2BWorkspace)  # 导入 E2B 工作空间类（图中未使用），用于在云端沙盒环境运行
from agentscope.model import OpenAIChatModel  # 导入模型类，用于实例化兼容 OpenAI 接口的大模型
from agentscope.credential import OpenAICredential  # 导入凭证类，用于配置 API Key 和 Base URL
from agentscope.tool import Toolkit
from agentscope.state import AgentState
from agentscope.permission import PermissionContext, PermissionMode  # 补全权限上下文相关导入

# ==========================================
# 2. 初始化工作空间 (Workspace)
# ==========================================
workspace = LocalWorkspace(workdir="./my_agent_workspace")  # 实例化本地工作空间，指定工作目录为当前目录下的 my_agent_workspace 文件夹
await workspace.initialize()  # 异步初始化工作空间（例如：创建目录、检测环境依赖等）

# ==========================================
# 3. 初始化大语言模型 (LLM)
# ==========================================
model = OpenAIChatModel(  # 实例化聊天模型对象
    credential=OpenAICredential(  # 内联传入 API 凭证对象
        api_key="xxx",  
        base_url="xxx",  
    ),
    model="qwen3.6-flash",  
)

# ==========================================
# 4. 工具获取与 Agent 实例化
# ==========================================
tools = await workspace.list_tools()  # 异步获取该工作空间下可用的所有工具（例如读写文件、执行代码等工具列表）

# 定义全局配置
permission_context = PermissionContext(
    mode=PermissionMode.DEFAULT,  # 默认安全模式：只读操作自动放行，其他操作询问用户
)

agent = Agent(  # 实例化智能体（Agent）
    name="my_assistant",  # 为智能体命名为 "my_assistant"
    system_prompt="你是一个有帮助的助手。",  # 设置系统提示词，定义智能体的角色和基础行为
    model=model,  # 将前面配置好的大模型绑定给智能体
    toolkit=Toolkit(tools=tools),  # 将获取到的 tools 绑定到工具箱中
    offloader=workspace,  # 设置卸载器为工作空间。Agent 在执行复杂任务或涉及文件读写时，会把具体操作“卸载”交给工作空间来处理
    state=AgentState(permission_context=permission_context),  # 设置 Agent 的状态，并传入权限上下文
)
```
