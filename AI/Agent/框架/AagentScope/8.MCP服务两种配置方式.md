# MCP 服务两种配置方式

- 远程网络服务模式 (Http-Stream)
- 本地进程模式 (Local / stdio)




# 网络远程模式 (Streamable HTTP)

运行方式：将 MCP Server 启动为一个网络服务（Web Service），并监听指定的 IP 和端口（host="0.0.0.0", port=8000）。

通信机制：基于 Streamable HTTP 协议。客户端通过 URL 连接，支持完整的双向通信（双向流式传输），适合处理复杂的交互。

特点：多客户端支持。一个服务端可以同时处理多个客户端的并发请求，无需为每个客户端创建独立进程。


## 示例

这套方案包含两个文件，必须先启动服务端，再运行客户端。

终端一：python server_http.py (保持运行)

终端二：python client_http.py


### server_http.py (服务端)

```python
from mcp.server.fastmcp import FastMCP
import urllib.parse

# 1. 初始化服务，指定网络地址和端口
mcp = FastMCP("remote_mcp", host="0.0.0.0", port=8000)

@mcp.tool()
def add(a, b):
    """将两数相加"""
    return str(float(a) + float(b))

@mcp.resource("name://{str_}")
def my_resource(str_):
    """读取问候资源"""
    return f"尊敬的{urllib.parse.unquote(str_)}, 你好"

if __name__ == '__main__':
    # 2. 以 HTTP 流模式启动服务
    print("服务端已启动，监听端口 8000...")
    mcp.run(transport='streamable-http')
```

### client_http.py (客户端)

```python
import asyncio
from mcp import ClientSession
from mcp.client.streamable_http import streamable_http_client

async def main():
    # 1. 连接到服务端的 URL
    async with streamable_http_client("http://localhost:8000/mcp") as a:
        read, write = a[:2]
        
        async with ClientSession(read, write) as session:
            # 2. 初始化会话
            await session.initialize()
            
            # 3. 调用工具
            result = await session.call_tool(
                "add",
                arguments={"a": 1.1, "b": 2.2}
            )
            print("调用 'add' 工具的结果:", result)
            
            # 4. 读取资源
            resource_content = await session.read_resource("name://小花")
            print("读取资源的结果:", resource_content)

if __name__ == "__main__":
    asyncio.run(main())
```


# 本地进程模式 (Stdio)

运行方式：标准输入/输出（STDIO） 模式。客户端（如 Claude Desktop）将服务端作为一个子进程启动，通过标准输入（stdin）和标准输出（stdout）流进行通信。

通信机制：直接通过进程间管道通信，不经过网络，因此延迟极低，安全性也更高。

特点：单客户端、单会话。每个客户端连接都会启动一个独立的后端进程，进程随客户端需求而生，随会话结束而灭。


## 示例

这套方案同样包含两个文件，但客户端会直接启动服务端，你不需要提前手动运行服务端。

终端：python client_stdio.py （只需运行这一个，它会自动拉起服务端，运行完毕后自动关闭进程）

### mcp_server_stdio.py (服务端)

注意：这个文件名必须和客户端里配置的文件名一致

```python
from mcp.server.fastmcp import FastMCP
import urllib.parse

# 1. 初始化服务，不需要指定网络端口
mcp = FastMCP("local_mcp")

@mcp.tool()
def add(a, b):
    """将两数相加"""
    return str(float(a) + float(b))

@mcp.resource("name://{str_}")
def my_resource(str_):
    """读取问候资源"""
    return f"尊敬的{urllib.parse.unquote(str_)}, 你好"

if __name__ == '__main__':
    # 2. 以本地 Stdio 模式启动服务
    mcp.run(transport="stdio")
```

### client_stdio.py (客户端)

客户端将通过 Python 解释器直接启动上面的 mcp_server_stdio.py

```python
import asyncio
from mcp import ClientSession, StdioServerParameters
from mcp.client.stdio import stdio_client

async def main():
    # 1. 配置启动本地服务端的命令
    server_params = StdioServerParameters(
        command="python",
        args=["mcp_server_stdio.py"] # 对应服务端的文件名
    )
    
    # 2. 客户端拉起子进程，并建立输入输出流
    async with stdio_client(server_params) as (read, write):
        async with ClientSession(read, write) as session:
            # 3. 初始化会话
            await session.initialize()
            
            # 4. 调用工具
            result = await session.call_tool(
                "add",
                arguments={"a": 1.1, "b": 2.2}
            )
            print("调用 'add' 工具的结果:", result)
            
            # 5. 读取资源
            resource_content = await session.read_resource("name://小花")
            print("读取资源的结果:", resource_content)

if __name__ == "__main__":
    asyncio.run(main())
```



# ClientSession 的作用

无论是网络还是本地，客户端都需要通过 ClientSession 将底层的通信流（Read/Write）包装成高层的 MCP 协议会话，之后才能调用 initialize、call_tool 等方法。



# 两者核心区别总结：

| 对比项 | 方案一 (HTTP 结合版) | 方案二 (Stdio 结合版) |
| :--- | :--- | :--- |
| **服务端状态** | 常驻后台运行 | 随客户端启动而生，随客户端结束而亡 |
| **通信介质** | 本地网络 (TCP / 127.0.0.1) | 操作系统管道 (stdin / stdout) |
| **启动顺序** | **先**启动 Server，**后**启动 Client | 只启动 Client 即可 |
| **多客户端支持** | ✅ 支持（可以同时开多个客户端连它） | ❌ 不支持（每次只能一对一连接） |
