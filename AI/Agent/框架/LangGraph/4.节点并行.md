
# 并行收集信息，随后汇总


在 LangGraph 中，`builder.add_edge(["c", "d"], "a")` 这里的**数组（列表）表示“多对一”的汇聚（Fan-in）逻辑**。

**只有当列表里的所有节点（"c" 和 "d"）都执行完毕后，才会触发目标节点（"a"）的执行。**


### 1. 对比单节点依赖
如果是普通的 `builder.add_edge("c", "a")`：
* **含义**：当节点 "c" 执行完毕后，立刻执行节点 "a"。这是 1 对 1 的关系。

### 2. 为什么用数组 `["c", "d"]`？
当你传入一个列表时，它相当于一个**同步屏障（Barrier）**或**等待点**：
* **含义**：必须等节点 "c" 完成**并且**节点 "d" 也完成，节点 "a" 才能开始执行。这是多对 1 的关系。

### 3. 实际的业务场景（为什么要这么写？）
这种设计通常用于**并行执行后的结果汇总**。
假设你正在构建一个多智能体系统或复杂的工作流：

* **分叉（Fan-out）**：入口先分发给两个并行的节点 "c" 和 "d"（比如 "c" 负责查数据库，"d" 负责调用外部 API 查资料）。
* **汇聚（Fan-in）**：这两个任务可以同时进行。当它们都处理完后，把结果汇总，统一交给节点 "a"（比如 "a" 负责综合两份资料生成最终答案）。



```python
import operator
import time
from typing import Annotated
from typing_extensions import TypedDict
from langgraph.graph import StateGraph, START, END

# ==========================================
# 1. 定义状态 (带 Reducer)
# ==========================================
class State(TypedDict):
    # 核心关键：使用 Annotated 配合 operator.add 作为 Reducer
    # 这意味着每次节点返回 {"logs": [...]} 时，不会覆盖，而是追加（类似于 list.extend）
    logs: Annotated[list[str], operator.add]
    final_result: str


# ==========================================
# 2. 定义并行节点 (c 和 d)
# ==========================================
def node_c(state: State):
    print("-> 节点 C 开始执行...")
    time.sleep(1) # 模拟耗时操作，如查询数据库
    print("-> 节点 C 执行完毕")
    # 直接返回要追加的列表，不需要手动去拼 state["logs"]
    return {"logs": ["节点C的查询结果"]}

def node_d(state: State):
    print("-> 节点 D 开始执行...")
    time.sleep(1.5) # 模拟耗时操作，如调用外部 API
    print("-> 节点 D 执行完毕")
    return {"logs": ["节点D的查询结果"]}


# ==========================================
# 3. 定义汇聚节点 (a)
# ==========================================
def node_a(state: State):
    print(f"-> 节点 A (汇总节点) 开始执行，当前接收到的日志: {state['logs']}")
    
    # 将数组合并成字符串，作为最终结果
    combined_result = " | ".join(state['logs'])
    return {"final_result": f"汇总完毕: [{combined_result}]"}


# ==========================================
# 4. 构建图结构
# ==========================================
builder = StateGraph(State)

# 添加节点
builder.add_node("c", node_c)
builder.add_node("d", node_d)
builder.add_node("a", node_a)

# 分叉：START 同时连接到 c 和 d
builder.add_edge(START, "c")
builder.add_edge(START, "d")

# 汇聚：多对一（等待 c 和 d 全部完成，才执行 a）
builder.add_edge(["c", "d"], "a") 

builder.add_edge("a", END)

# 编译图
app = builder.compile()


# ==========================================
# 5. 执行图
# ==========================================
print("--- 开始执行工作流 ---")
initial_state = {"logs": []} # 初始状态给一个空列表
final_state = app.invoke(initial_state)
print("--- 工作流执行完毕 ---")
print(f"最终状态: {final_state}")

```
