# 并行

多个 Agent 同时执行，

场景一：从多个结果中取一个最优的答案，提升效率。

场景二：翻译字幕，需要同时输出中英双语言。

```python
agent_a = Agent(
    name="AI助手",
    instructions="使用中文进行回答",  # 系统提示词
)

agent_b = Agent(
    name="AI助手",
    instructions="使用英文进行回答",  # 系统提示词
)

agent_c = Agent(
    name="AI助手",
    instructions="使用韩文进行回答",  # 系统提示词
)

async def main():
    query = '请问太阳围绕地球，还是地球围绕太阳？？'
    t1 = time.time()

    result_1, result_2, result_3 = await asyncio.gather(
        Runner.run(agent_a, query),
        Runner.run(agent_b, query),
        Runner.run(agent_c, query),
    )

    t2 = time.time()
    print(result_1.final_output)
    print(result_2.final_output)
    print(result_3.final_output)

    print(t2 - t1)
```
