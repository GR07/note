# 概念

在《人工智能》书中将智能体的概念确定为研究人工智能的方法的核心。

如何从人工智能到通用人工智能，agent承载这样一个角色，方便机器和人类的沟通。

定义：通过传感器能感知到环境，再通过执行器改变环境，就可以称为智能体。

例如：自动驾驶、扫地机器人、游戏中的人机、还有基于大语言模型的智能体，这些都是智能体。


# 学术-智能体三个部分组成

- 感知模块

通过多模态（图片、文字、音频、视频）得到信息。再转换成向量（大模型可以理解的内容）。

- 大脑模块（大语言模型）

做思考、做决策，有短期、长期记忆

- 行动模块

执行决策和任务的安排


# 实际开发落地

agent = 大模型 + 长短期记忆存储 + 规划能力 + 工具




# 产品进化过程

- 聊天机器人：只能聊天

- AI助理：除了聊天外，还集成了一些工具，但是需要指挥他去用具体工具做事。（部门做的只是这个阶段而已）

- AI智能体：有自己的判断，以任务目标为导向，可以自己主动的去拆分任务执行。（没有普及，今天的方向）
