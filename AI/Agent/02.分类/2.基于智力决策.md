# 基于智力水平、决策过程

细分 5 类

## 简单反射智能体

特点：不会思考，只通过预定规则做出决策，响应快速。

例:

恒温水壶：感知温度小于45度 -> 内部找到规则命中 -> 做出加热动作

智能驾驶：感知前车刹车灯 -> 内部找到规则命中 -> 我方刹车


## 基于模型的反射智能体

对比简单反射智能体，内置维护了一个模型，感知后，根据历史进行思考预测未来，再做出决策。

特点：相对灵活一些，一定程度提高决策的准确性。


## 基于目标的智能体

前面两个智能体都是反射，一旦感知到环境变化，马上就做出决策。

而基于目标的智能体如下：

最开始制定一个目标 -> 感知到环境变化 -> 思考做出决策 -> 再思考这个决策对任务目标有没有帮助 -> 最后做出最终决策


## 基于效能的智能体

对比基于目标的智能体，做出最终决策之前，会根据历史进行评估哪条路线是最优解，再做出决策。


## 学习型智能体 - 理想型

对比基于效能的智能体，基于效能的评估是根据历史的，随着时代的变迁可能差较大。

所以需要不断的根据环境的变化而学习消化，才能及时的对环境变化做出最准确的决策。

这就是 学习型智能体
