# 指定模型输出的数据格式

作用：避免模型输出的自然语言冗长产生理解歧义。结构化的输出可以用于下一轮的输入。


不同模型，支持程度不一样，所以最将数据结构的约束写在提示词里，拿到结果后自己用 Python 的 Pydantic 或 json.loads() 来解析，这是目前对接国产大模型最稳定、坑最少的做法。

注：部分模型支持 output_type 属性

```python
# 从 pydantic 库中导入 BaseModel 类，用于定义数据模型
from pydantic import BaseModel
import asyncio
import json

from agents import Agent, Runner
import config

# 定义一个名为 Data 的类，继承自 BaseModel，用于结构化输出数据
class Data(BaseModel):
    名字: str
    年龄: int
    性别: str
    事迹: str

agent = Agent(
    name="AI助手",
    # 设置代理的指令（系统提示词），告诉它该如何表现
    instructions="""你是一个友好的AI助手。使用中文进行回答。
请严格按照以下 JSON 格式输出结果，不要包含任何其他解释或 markdown 代码块标记：
{
  "名字": "人物名字",
  "年龄": 年龄数字,
  "性别": "男/女",
  "事迹": "人物事迹简述"
}""",
    model='deepseek-flash',
)

# 定义异步主函数 main
async def main():
    result = await Runner.run(agent, '介绍一位值得记住的人？')

    output_text = result.final_output

    # 使用 try-except 块来捕获可能出现的解析错误
    try:
        # 使用 Pydantic 模型的 model_validate_json 方法验证并解析 JSON 字符串
        obj = Data.model_validate_json(output_text)
        print("--- 解析成功 ---")
        print(result.final_output)
        print(obj.名字)
        print(obj.性别)
        print(obj.事迹)
        print(result.to_input_list())
    # 捕获异常
    except Exception as e:
        print("解析 JSON 失败，模型原始输出为：")
        print(output_text)
        print(f"错误信息: {e}")

if __name__ == '__main__':
    asyncio.run(main())
```
