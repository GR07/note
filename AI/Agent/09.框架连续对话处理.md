# 为什么需要连续对话？



## 问题如下：

我们理想的答复是 3

但模型却回答：需要知道“再”前面的数是多少才能算哦。

所以模型会当作这是两次对话

```python
result = await Runner.run(agent, '1+1等于多少')  
result = await Runner.run(agent, '再+1等于多少')  
# LLM 回复：需要知道“再”前面的数是多少才能算哦。
print(result.final_output)  
```


## 改造 方式一

创建一个全局变量 list 每次对话都 append list ，始终传递模型这个列表


## 改造 方式二

把结果转成列表 to_input_list ，再 append，可以不断的去 to_input_list

```python
# 异步运行智能体，等待用户输入问题后传给 agent，将结果赋值给 result
result = await Runner.run(agent, '1+1等于多少')  

history = result.to_input_list()  # 将结果转换为输入列表，方便后续使用

history.append({ "role": "user", "content": "再+1等于多少" })

result = await Runner.run(agent, history)  

# LLM 回复：在刚才的结果 **2** 的基础上再 **+1**，等于 **3**。
print(result.final_output)  
```


## 总结

核心就是不断的操作列表，完整列表发给下次对话


## 注：不同 agent 的方式有差异化，上面是 openai
