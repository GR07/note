# 短期记忆

AI 需要依靠短期记忆，记住你上一句问了天气，才能回答这句的穿衣建议。


# 长期记忆

长期记忆是跨“会话”的，是跟着用户（User ID）走的，而不是跟着某一次聊天走的。


# 结合 LLM

无论是短期记忆还是长期记忆，最后都会送给 LLM。大模型结合“你刚说的话（短期）”和“它以前知道的你（长期）”，生成最完美的回复。


# 持久化层

再次强调，不管短期还是长期，必须存到硬盘里（激活持久化），不然一断电全白搭。


# 线程与会话关系

在 AI 开发里，**“线程（Thread）” ≈ “一次独立的聊天会话”**。比如你在网页上点击“新建对话”，那就是开了一个新线程。


---


# 总结

1.  **记忆是认知功能**：AI 得能**存**、能**找**、能**用**这些信息。
2.  **记忆是为了保持上下文**：别聊着聊着天，AI 忘了自己刚才在干嘛。
3.  **记忆需要结构化**：不能像一团乱麻一样存，要分类（比如“用户画像表”、“历史事件表”），这样找起来才快。
4.  **记忆需要高效检索**：档案太多了，AI 得知道当前的问题该去哪个档案袋里找答案。
5.  **如何融入对话**：找出来的记忆，怎么巧妙地塞进给大模型的提示词（Prompt）里，这也是个技术活。
