# 滑动窗口截取

只记住最近几句，早期的忘掉

由于模型有 Token 长度限制，我们不能把历史上所有的对话都发给模型。通常的做法是只保留最近的几条对话，这就叫“滑动窗口”。


```python
message_history = []

system_prompt = """
我是系统提示词
"""

message_history.append({"role": "system", "content": system_prompt})

message_history.append({"role": "user", "content": "用户提示词1"})
message_history.append({"role": "user", "content": "用户提示词2"})
message_history.append({"role": "user", "content": "用户提示词3"})
message_history.append({"role": "user", "content": "用户提示词4"})

def context_sliding_window(message_list: list, k=2):
    """
    实现对话历史的滑动窗口功能，保留最近的 k 轮对话。
    
    参数:
        message_list (list): 包含对话历史的消息列表，每个元素通常是类似 {'role': 'user', 'content': '...'} 的字典。
        k (int): 保留的轮数（默认值为2）。
    
    返回:
        list: 处理后的消息列表。
    """
    
    # 核心逻辑：利用 Python 列表切片保留最后 k*2 条消息
    # 为什么是 k*2？因为通常一轮对话包含一条用户消息和一条AI回复，所以 k 轮 = 2k 条消息。
    # 切片操作 [k*-1:] 等价于 [-2k:]，即从倒数第 2k 个元素截取到列表末尾。
    new_message_list: list = message_list[k*-1:]

    # 如果丢失了系统提示，则手动补上
    # 检查截取后的列表第一条消息是否为系统提示（system prompt）
    if new_message_list[0]['role'] != "system":
        # 如果截取后的列表里没有系统提示，检查原始列表的第一条是否为系统提示
        if message_list[0]['role'] == "system":
            # 如果是，则将原始列表的第一条（系统提示）插入到新列表的开头
            # 这样保证了即使窗口滑动了，系统设定（如“你是一个AI助手”）依然存在
            new_message_list.insert(0, message_list[0])

    # 返回处理后的消息列表
    return new_message_list

# 调用函数并打印结果
print(context_sliding_window(message_history))
```
